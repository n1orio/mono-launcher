# Изменения

## [1.3.1] — 2026-08-18

### Моды и хранилище
- Новая вкладка **«Дубликаты»** сканирует `mods/`, `resourcepacks/` и `shaderpacks/` и группирует файлы с одинаковым содержимым (по размеру + SHA-1). Показывает, сколько места можно освободить, позволяет удалить один файл или оставить по одному в группе.

### Скриншоты
- Скриншоты теперь показывают **дату и время** снятия — бейджем на каждой плитке и в полноэкранном просмотре.

## [1.3.0] — 2026-08-18

### Библиотека
- Новая вкладка **«Библиотека»**: все установленные сборки, сгруппированные по категориям, плитки с масштабированием (зум).
- Каждая плитка показывает активный модлоадер/версию или «не установлено»; категории можно скрывать.
- Новый раздел **«Недавние»** в сайдбаре показывает ваши последние запущенные сборки (до 10).

### Брендинг сборок
- **Переименование сборки** прямо из интерфейса — пользовательские имена встроенных сборок хранятся для каждого экземпляра, у пользовательских обновляется `packs.json`.
- **Загрузка своего баннера** (редактирование иконки уже было) — хранится локально для каждой сборки.

### Моды и обновления
- Установленные вручную моды теперь показывают реальные метаданные — иконку Modrinth/CurseForge, название проекта и версию — вместо сырых имён файлов.
- **«Обновить все» теперь по вкладкам** (моды / ресурспаки / шейдеры), со счётчиком.
- Поиск Modrinth получил **фильтр типа версии** (Релиз/Бета/Альфа), фильтр загрузчика, «Загрузить ещё» и «Сбросить фильтры».
- Зависшие записи отслеживаемых модов (файлы уже удалены с диска) чистятся, так что значок обновления больше не показывает призрачные обновления.

### Геймплей и интерфейс
- Пока игра запущена, кнопка «Играть» превращается в красную **«Остановить»**, завершающую процесс, с корректным выходом (без ложного «игра упала» при намеренной остановке).
- Основная панель интерфейса теперь **по центру** экрана, а не растягивается от края до края.

### Под капотом
- Новый персистентный **HTTP-кеш** (условные запросы ETag/304), чтобы повторные запуски лаунчера не дёргали сеть без изменений.
- Расширены Rust-юнит-тесты; проверка типов фронтенда.
