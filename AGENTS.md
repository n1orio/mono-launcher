# AGENTS.md

Desktop Minecraft modpack launcher. **Tauri 2** (Rust backend) + **Nuxt 3 / Vue 3 + TypeScript + Tailwind** (Vite-based frontend). Modpack is distributed as a `.mrpack` hosted on GitHub Releases.

## Commands
- `npm run dev` — Nuxt dev server on port **1420** (SSR is off — this is a SPA inside Tauri).
- `npm run tauri dev` — dev app (starts Nuxt dev then Rust). Vite devUrl served at `localhost:1420`.
- `npm run build` — `nuxt typecheck && nuxt build`. This is the **typecheck/CI test**. Output (SSG/static SPA) lands in `dist/`, which is what Tauri bundles.
- `npm run tauri build` — release binary; runs `npm run build` first (via `beforeBuildCommand`).
- `npm run tauri:appimage` — Linux AppImage; requires `NO_STRIP=true` (already set in script). AppImages fail to strip properly on many toolchains.
- Rust checks: `cargo check` / `cargo clippy` from `src-tauri/`. **Unit tests exist**: `cargo test --lib` (deep link parser in `lib.rs`, custom-file source classification in `mrpack.rs`) — run this before committing Rust changes. There is no TS test framework; the TS check is `npm run build`.
- Headless UI smoke: `scripts/dev-headless.sh` (Xvfb on `DISPLAY_HEADLESS`, default `:99`, software GL + WebKit workarounds).

## Layout
- `pages/index.vue` — the whole UI (the only page). `composables/useLauncher.ts` holds all state + handlers.
- `lib/` — `bridge.ts` (typed wrapper over `@tauri-apps/api` `invoke`/`listen`) and `types.ts`. **Add new Tauri commands here.**
- `composables/useI18n.ts` — flat ru/en dictionaries, keys via `t()`. **Add every new key to BOTH dictionaries.**
- `assets/css/main.css` — global CSS, Tailwind entry and **theme CSS variables** (`--bg`, `--panel`, `--input`, `--border`, `--tx*`, alpha variants like `--input-50`). UI colors are `var(--*)`-based: **never hardcode colors in `index.vue`**; theme is toggled by adding `.theme-light` to `documentElement` and persisted under localStorage key `nio.theme` (see `applyTheme`/`toggleTheme` in `useLauncher.ts`).
- `src-tauri/src/` — Rust backend. `lib.rs` registers all `#[tauri::command]`s in `run()`. Modules: `config.rs` (`PACKS` list + paths), `mrpack.rs` (download/install), `auth.rs` (offline + MS OAuth), `game.rs` (Java launch).

## Gotchas
- This is `ssr: false` + Nitro `preset: static` producing `dist/`. It is a desktop SPA talking to the Rust backend at runtime: **browser-only APIs** (`window`, `navigator.clipboard`, etc.) are used in `composables/useLauncher.ts`; guard all Tauri IPC calls with `isTauri()`.
- **Build race**: a running `npm run tauri dev` watcher wipes `dist/` — never run `npm run build` while the dev app is alive (parallel builds corrupt the output; run release builds after stopping dev).
- Dev/typecheck quirks: Nuxt's generated `tsconfig.json` (`include: ../**/*`) will pull in `src-tauri/target` binary JS. The root `tsconfig.json` overrides `exclude` to keep typecheck clean — if you touch build artifacts or add large dirs, extend that exclude list.
- Packs: built-in `PACKS` in `src-tauri/src/config.rs` + **user-added registry** `packs.json` in the launcher root (anyone can add a GitHub repo whose releases contain a `.mrpack` — `add_pack_impl` validates this, id = `owner-repo` slug). `config::all_packs()` / `find_pack` merge both; `PackInfo` (owned, `builtin` flag) is used everywhere. `PackDescriptor.author` comes from the GitHub owner in the pack URL (`repo_author`) and is shown in the sidebar/play header/dev list. Every pack-related command takes `pack_id` (JS camelCase `packId`, nullable → default pack). `parse_github_repo` returns `None` for `USER`/`REPO` placeholders (skips GitHub API). Pack repo content (`pack_repo_content_command`): GitHub stars via `api.github.com/repos/...` + `screenshots.json` (array or `{"files":[...]}`, images only) and `servers.json` (`[{name, ip, port?, desc?}]`) fetched raw at HEAD from `raw.githubusercontent.com` (no API quota); result cached as `PackRepoContent` in `ApiCache.meta` (15 min). Served in the play tab as "Screenshots"/"Servers" subtabs + stars in the pack header. The **Screenshots subtab no longer uses `screenshots.json`** — it lists the local `screenshots/` folder of the installed version (`list_screenshots_command`, image extensions png/jpg/jpeg/webp/bmp/gif; displayed via Tauri asset protocol `convertFileSrc` — needs `protocol-asset` feature + `security.assetProtocol` scope; lightbox in the app). The **Servers subtab splits into two groups** (`serverGroups` computed in `index.vue`): pack servers from `servers.json` on top, then the player's own servers from `servers.dat` of the installed version (`list_servers_command`; `nbt.rs` parses gzip+NBT — saved-server entries are list-compounds with no tag byte/name, `SavedServer{name,address}`, address may contain `host:port`). Server cards ping via `ping_server_command` (`ping.rs`: Minecraft 1.7+ status request, protocol 767 in handshake, packet id skipped — old proxies reply `id=-1`; fallback to legacy 0xFE) and "Играть на сервере" (`playOnServer` → `launch_game_command(serverAddress)` → `game::ServerAddress` + `--server`/`--port` game args). Statuses refresh every 45 s while the Servers tab is open (`serverPingTimer` in `index.vue`).
- **Deep links**: Tauri scheme `niol` (`tauri.conf.json`), used as `niol://add-pack?url=<encoded>&name=<encoded>` to add a pack in one click. Plugins `tauri-plugin-deep-link` + `tauri-plugin-single-instance` — **`single-instance` must be registered before `deep-link` in `run()`**, and `register_deep_link_handlers` runs in `setup()`. New URLs arrive via the `deep-link://new-url` listener AND an argv scan + `get_current()` at startup; duplicates go through `HANDLED_LINKS`; the added pack is pushed to the UI via the `pack-added` event or `take_pending_pack_add` (first-launch race). Frontend: `onPackAdded`/`takePendingPackAdd` in `useLauncher.ts`.
- **Universal invite link** (bridge page): `https://n1orio.github.io/nio-launcher/?url=<encoded>&name=<encoded>` — gh-pages branch of THIS repo; auto-opens `niol://`, falls back to a download CTA. `inviteLinkFor()` in `index.vue` builds it.
- **Custom mods / integrity**: `mrpack.rs` treats mods as trusted only when downloaded from the whitelist in `TRUSTED_DOWNLOAD_HOSTS` (Modrinth/CurseForge CDNs). Every downloaded file is hash-verified post-download against `modrinth.index.json` (`sha1`/`sha512`); a mismatch removes the file and fails the install. Files from untrusted hosts plus `.jar`s in `overrides` are recorded in `.nio-custom.json` per version, surfaced as `AppStatus.custom_mods` and shown in a warning banner in the play tab. Don't weaken these checks without a reason.
- **News feed** (`get_news_command`): pack releases + pack discussions + **launcher's own GitHub releases** (`NEWS_REPO = n1orio/nio-launcher`, `fetch_launcher_releases_cached`) as `pack_id: "launcher"`. News items for `pack_id === "launcher"` render an "open release page" button, NOT an install button.
- UI: **each pack has its own nav tab** (`openPackTab` in `index.vue`); there is no sidebar pack `<select>` anymore — switching happens via the tabs.
- Per-pack data lives in `~/.local/share/NioLauncher/packs/<pack_id>/` (versions/, active.json, mrpack-cache/); shared runtime data (libraries, assets, launch.log) is in the root — see README.
- Release changelogs (tag + body + published_at) come from the GitHub `releases` API — see `fetch_repo_releases` / `GhVersion` in `lib.rs`. API answers are cached (15 min, failures 60 s) in `ApiCache`.
- When you add/rename a Rust command, update `lib/bridge.ts` AND the `generate_handler!` list in `src-tauri/src/lib.rs`.
- Tauri 2 IPC commands are invoked camelCase on the JS/Vue side → snake_case in Rust (`launch_game_command`).
- Port 1420 must stay fixed — Tauri devUrl depends on it (`vite.server.strictPort`).
- `bundle.createUpdaterArtifacts: true` in `tauri.conf.json` — билд требует подписи minisign, иначе падает. Локально: `export TAURI_SIGNING_PRIVATE_KEY="$(cat ~/.tauri/nio-launcher.key)"` и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD="$(cut -d= -f2 ~/.tauri/nio-launcher.passphrase)"` (ключ в `~/.tauri/`, дубликат в GitHub secrets репо — НЕ коммитить).
- Автообновление лаунчера: `tauri-plugin-updater` + статический `latest.json` в релизе. `scripts/make-updater-json.mjs` собирает его из ассетов (нужны `.sig` рядом с бандлами); джоба `update-manifest` в CI делает это после сборки. Endpoint `releases/latest/download/latest.json` — работает только когда релиз опубликован (не draft).
- The repo **is** a git repo (branch `main`, tracks `origin/main`); sessions often leave uncommitted work — check `git status` before editing, and commit only when asked.
- Version the launcher with `launcher-v*` tags (`.github/workflows/build-launcher.yml`). The pack `.mrpack` is built manually in Prism Launcher and uploaded to GitHub Releases by hand.
- E2E deep-link check (Linux): after `npm run tauri build`, verify the scheme handler with `xdg-mime query default x-scheme-handler/niol`, then trigger `xdg-open "niol://add-pack?url=<enc>&name=<enc>"` under Xvfb and inspect `~/.local/share/NioLauncher/packs.json`.
