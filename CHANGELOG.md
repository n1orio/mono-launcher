# Changelog

## [2.0.0-alpha.6] — 2026-08-30

### CurseForge
- **Loader filter** — CurseForge modpack search now filters by `modLoaderType` (forge / fabric / quilt / neoforge) instead of `categoryId`.
- **Auto-filters** — opening a pack automatically applies filters from pack status (lo loaders, mod loaders).
- **Full descriptions** — CurseForge modpack cards render full HTML descriptions (with prose styling) instead of truncated summary.
- **Infinite scroll** for search results.

### Context menus
- Right-click a pack in the sidebar → Play / Settings / News / Remove.
- Right-click a file in the file list → View Detail / Update / Enable-Disable / Delete / Open Folder.
- Reusable `AppContextMenu` and `AppContextMenuItem` components.

### Toolbar
- "..." menu with sections: mod management, file operations, delete.
- Delete button moved into dropdown (red trash icon).

### UI
- Font scale: 13px → 14px.
- Window size: 1200×750, minimum 950×650.
- `enableAllFiles()` helper for bulk enable/disable operations.

### Fixes
- Restored missing component files (tabs/, modals/).
- Version bumped to 2.0.0-alpha.6 across package.json, tauri.conf.json, Cargo.toml, and all locale files.

## [2.0.0-alpha] — 2026-08-24

### Library & packs
- **Custom categories** — create, rename and delete your own categories; assign any pack to multiple of them via the tile context menu. Sections collapse state is remembered.
- **Library search** — instantly filter all pack sections by name.
- **Drag & drop install** — drop a `.mrpack` file onto the launcher window to add it.
- **System tray** — tray icon with menu (show/quit), optional "close to tray" behavior and "launch at system startup" toggle in Settings → System.

### Author panel
- **Markdown editor** for pack description and news — toolbar (bold/italic/code/list/heading/link) with live preview.
- **Screenshot captions** — add a caption when uploading or adding by URL, edit inline later; shown under screenshots in the catalog.
- Overview form: banner field with preview, dirty-tracking Save/Reset, two-step delete confirmation (danger zone), copy-link / open-in-catalog shortcuts.

### Downloads & resources
- **CurseForge version picker** — resource detail window now has a Versions tab with game-version filter; install any specific file, not just the latest.
- Child windows (resource details, CurseForge search) are now frameless with a custom title bar matching the app theme.

### Interface
- Refined dark theme: borders removed from elements, gradients replaced with flat colors.
- Larger typography scale across the app and bigger collapsed-sidebar icons.
- Smooth slim scrollbars on tab strips; theme slider now persists its level and syncs across all launcher windows live.

## [1.3.1] — 2026-08-18

### Mods & storage
- New **Duplicates** tab scans `mods/`, `resourcepacks/` and `shaderpacks/` and groups files with identical content (by size + SHA-1). Shows how much space could be freed, lets you delete a single file or keep just one per group.

### Screenshots
- Screenshots now show the **date and time** of the shot — as a badge on each tile and in the full-screen viewer.

## [1.3.0] — 2026-08-18

### Library
- New **Library** tab: all installed packs grouped by category, sortable tiles with zoom in/out.
- Each tile shows the active modloader/version or "not installed"; categories can be toggled.
- New **Recent** section in the sidebar shows your last launched packs (up to 10).

### Pack branding
- **Rename a pack** right from the UI — custom names for built-in packs persist per install, user packs update in `packs.json`.
- **Set a custom banner** image (icon editing was already supported) — stored locally per pack.

### Mods & updates
- Manually installed mods now display real metadata — Modrinth/CurseForge icon, project title and version — instead of raw file names.
- **"Update all" is per-tab** (mods / resourcepacks / shaders), with a live count badge.
- Modrinth search gains a **version-type filter** (Release/Beta/Alpha), loader filter, "Load more" and "Reset filters".
- Stale tracked-mod entries (files already deleted on disk) are cleaned up, so the update badge no longer shows phantom updates.

### Gameplay & UI
- While the game is running the Play button becomes a red **Stop** button that terminates the process, with clean exit handling (no false crash report on intentional shutdown).
- The main interface pane is now **centered** on screen instead of stretching edge-to-edge.

### Under the hood
- New persistent **HTTP cache** (ETag/304 conditional requests) so repeated launcher runs don't refetch unchanged data.
- Rust unit tests extended; type-check gating for the frontend.

## [1.2.1] — 2026-08-16

### Авторизация (hotfix)
- Исправлен вход через Microsoft/Ely.by: `authorization_pending` (ожидание подтверждения кода) больше не падает — поля токена сделаны опциональными, лаунчер корректно поллит до подтверждения.
- Диагностические сообщения теперь показывают статус и тело ответа Azure/Minecraft Services (вместо сухих «не выдал device code» / «отклонил XSTS-токен») — проще найти причину (не-JSON, неверная регистрация приложения и т.п.).
- Добавлена поддержка Microsoft OAuth2: встроен Azure client ID.

### Запуск (hotfix)
- Исправлен запуск старых версий: библиотеки-«только natives» (у `net.java.jinput:jinput-platform` базового jar не существует — 404) больше не попадают на classpath, natives извлекаются корректно.
- Зеркало BMCLAPI для библиотек, которые Mojang удалил с `libraries.minecraft.net`.

## [1.2.0] — 2026-08-16

### Свои сборки: экспорт для автора
- Новый режим экспорта «Сборка для автора»: из собранной у себя сборки генерируется полный комплект публикации — конфиг пакета, README (на выбор ru/en/uk), моды/ресурспаки/шейдеры, серверы и соцсети с кнопками.
- **Авто-тема из акцентного цвета**: из одного цвета акцента автоматически собирается вся цветовая схема (`theme.json`, 11 полей) для лаунчера — интерфейс перекрашивается под бренд сборки.
- Тема настраивается вживую: цветовые поля с цветовым пикером и подписями; акцент задаётся или нативным выбором цвета, или авто-заполнением.
- Лимиты наполнения: до **5 серверов** и **4 соцсетей** — со счётчиками `n/5`, `n/4` и блокировкой «+» на пределе.
- Кнопки экспорта (`.mrpack` / Автор / CurseForge) сгруппированы в единый выпадающий список с подсказкой формата.
- Кнопка «Сообщить о баге» теперь показывается только для сборок с GitHub-репозиторием.

### Переводы и документация
- README лаунчера на **5 языках**: английский (основной), русский, украинский, немецкий, белорусский — с переключателем в шапке. Добавлен раздел «Почему публиковать сборку именно в этом лаунчере».
- **Немецкий и белорусский языки интерфейса** (новые локали) — выбор в настройках; набор ключей полный.
- Интерфейс, новые типы и команды бэкенда для экспорта автора; переводы en/ru/uk/de/be обновлены.

### Запуск: fix старых версией
- Исправлен запуск старых версий Minecraft: библиотеки-«только natives» (у `net.java.jinput:jinput-platform` базового `.jar` не существует и на CDN его нет — 404) больше не скачиваются на classpath, а natives корректно извлекаются. Дополнительно добавлено зеркало (BMCLAPI) для библиотек, которые Mojang удалил с `libraries.minecraft.net`.

## [1.1.1] — 2026-08-16

### Краш-репорты
- После сбоя игры лаунчер **сам анализирует свежие краш-артефакты** (`crash-reports/*.txt`, `hs_err_pid*.log`, хвост `logs/latest.log`): разбирает исключение и стектрейс, классифицирует известные причины и подсказывает «подозреваемый» мод (по совпадению пакетов из стека и jar-файлов сборки).
- При сбое в консоль/уведомление выводится подсказка; если причина связана с версией Java — лаунчер предлагает нужную версию.

### Java
- Автоподбор Java учитывает **требования модов** (`required_java_from_mods`): если моды сборки требуют более новую/старую Java, чем версия Minecraft, выбирается максимальная из требований.
- Корректный парсинг диапазонов версий Java (включая исключающие нижние границы вида `(,17]`).

### Скины (authlib-injector)
- Отдача метаданных не только на `/api/authlib-injector/checker`, но и на корень `/` — любой порядок пробинга API резолвится без 404/`FileNotFoundException`.

### Интерфейс
- Обновлён левый сайдбар: сводка статуса (установлена/нет, версия сборки, память, версия лаунчера), учётная запись, кнопка запуска, настройки темы/языка.
- Сабтабы вкладки сборки (Релизы/Моды/Ресурспаки/...) получили дефолтную заливку и явную обводку активной вкладки.

## [1.1.0] — 2026-08-16

### Свои сборки
- Изменение версии/загрузчика сборки прямо из списка сборок.
- **Версия Java по сборке**: для своей сборки можно указать нужную Java (8/17/21); лаунчер скачает именно её и будет запускать с ней.
- Экспорт сборки: **`.mrpack` (Modrinth)** или **`.zip` (CurseForge)** — с названием и версией, выбором файлов и папок через дерево.

### Запуск / Java
- Автоподбор версии Java под версию Minecraft: `1.21+/1.20.5+ → Java 21`, `1.17–1.20.4 → Java 17`, старшие → Java 8.
- Если нужной Java нет (или нашёлся старый Java), лаунчер **сам скачивает и распаковывает** её в `runtime/java-<версия>/` — отдельно от остальных. Раньше автоматически ставилась только JRE 21.
- Распознавание всех уже скачанных Java; устаревшая одиночная JRE в `runtime/bin` по-прежнему подхватывается.

### Моды и обновления
- Просмотр ресурса (мод/ресурспак/датпак): описание, версии и скриншоты — в модалке, с выбором версии.
- Обновление модов с Modrinth: исправлена установка с сервера — файл при переустановке заменяется, а не дублируется.

### Прочее
- Новые команды бэкенда и типы для всего вышеописанного; переводы en/ru/uk обновлены.

## [1.0.0] — 2026-08-14

Стабильный релиз. Собирает всё наработки из 0.2.x и 0.3.0-alpha.

### CurseForge
- Страница проекта CurseForge (как у Modrinth): описание, версии, скриншоты — открывается по клику на ресурс, с установкой выбранной версии.

- Чистые UI-хелперы вынесены из `useLauncher.ts` в `lib/`: `changelog.ts`, `format.ts`, `labels.ts`, `misc.ts`.

### Исправления
- Консоль/логи больше не отображается во вкладках «Моды», «Ресурспаки», «Шейдеры», «Миры», «Скриншоты» и «Серверы» (разорванная цепочка `v-else-if` из-за модалки просмотра ресурса).
- Clippy-чистка Rust-кода: арифметика без переполнения, упрощённые паттерны, `&Path` вместо `&PathBuf`.

## [0.2.5] — 2026-08-12

### Ely.by
- Вход через Ely.by в настройках (рядом с Microsoft): устройство-код с QR, как у Microsoft — никаких паролей, вход на официальной странице Ely.by.
- Профиль Ely.by (ник, UUID, скин) честно работает в игре и на серверах: сессия запускается через authlib-injector с официальным алиасом `ely.by`.
- Аккаунт Ely.by появляется в списке аккаунтов как отдельный тип («Ely.by»), переключение/удаление — как у остальных.
- Настройка: clientId приложения Ely.by кладётся в файл `<данные лаунчера>/ely-client-id` (или `NIO_ELY_CLIENT_ID`) — как Azure для Microsoft.

### CurseForge
- Кнопка «CurseForge» на вкладках «Моды», «Ресурспаки» и «Шейдеры»: поиск проектов и установка последней версии, подходящей под версию Minecraft сборки, со сверкой sha1.
- API-ключ задаётся через `NIO_CURSEFORGE_KEY` или файл `<данные лаунчера>/curseforge-key.txt` — без ключа модалка подскажет, как его задать.
- Единое окно поиска файлов: кнопка «Добавить» на вкладках файлов открывает плавающее перетаскиваемое окно с переключателем сервиса — Modrinth или CurseForge. Старые раздельные модалки удалены.
- Если поиск CurseForge отвечает 403/429 (ключ не принят, лимит запросов или сбой на их стороне), в окне поиска показывается конкретный статус и причина вместо голого текста «проверьте ключ».

## [0.2.2] — 2026-08-11

### Одна игра — один экземпляр
- Запуск второй копии Minecraft поверх уже открытой теперь блокируется (раньше можно было запустить игру дважды подряд): кнопка «Играть» гаснет на время игры («В ИГРЕ»), а при повторной попытке — ошибка «Игра уже запущена».
- Guard живёт в бэкенде: любой способ запуска (кнопка, «Играть на сервере», повторный клик) проверяет, не запущен ли уже клиент (PID игры хранится процессом и снимается при выходе).

### Ачивки → «ещё не запускалась»
- Бейджи-ачивки убраны: вместо них у свежеустановленной сборки показывается пилюля «Ещё не запускалась», которая сменяется часами после первого запуска.

## [0.2.0] — 2026-08-11

### Платные сборки через Boosty
- Платность сборки настраивается никем блога: опциональный `boostyBlog` в `pack.json` релиза, `packs.json` или встроенных `PACKS` (нет поля — сборка бесплатная).
- Игрок привязывает личный токен Boosty (Настройки Boosty → Приложения): лаунчер проверяет подписку на блог издателя через api.boosty.to — скачивание и запуск открываются только подписчикам (оффлайн-льгота до 3 дней после успешной проверки).
- Ссылка-приглашение несёт `blog=` — сборка добавляется сразу платной; `pack.json` с `boostyBlog` даёт тот же эффект.
- Панель подписки в шапке сборки: статус (до какой даты активна), поле токена, привязка/отвязка.

### Каталог сборок
- Новая вкладка «Каталог»: курируемый список сборок из `catalog.json` (в корне репозитория лаунчера) — описание, автор, теги, платность, минимальная оперативка; кнопки «Добавить» (один клик, с блогом из записи) и «Открыть» для уже добавленных.
- Кнопка «Предложить сборку» — issue с шаблоном для авторов.

### Минимальная оперативка
- Новое поле `minRam` (МБ) в `pack.json`: бейдж «≥ N ГБ» в шапке сборки, подсказка в настройках и блокировка запуска при недостаточном выделении ОЗУ.

### Баг-репорты
- «Сообщить о баге» открывает превью отчёта: окружение (включая RAM и разрешение окна) + хвост launch.log (60 строк) — можно скопировать или открыть Issues.

### Серверы сборок
- Вкладка «Сервера»: статусы серверов прямо в карточках — онлайн/офлайн, игроки, версия, MOTD, пинг (1.7+ status request с фолбэком на legacy 0xFE). Автообновление статусов раз в 45 секунд + кнопка «Обновить статус».
- Кнопка «Играть на сервере»: запускает игру с авто-коннектом (`--server`/`--port` в аргументах клиента).
- Серверы игрока из `servers.dat` установленной версии: показываются отдельной секцией «Мои серверы (из servers.dat)» под серверами автора сборки (адрес + порт парсятся автоматически).

### Скриншоты
- Вкладка «Скриншоты» теперь показывает скриншоты из папки `screenshots` установленной версии сборки (F2 в игре) — с полноэкранным просмотром. `screenshots.json` в репозитории больше не нужен.

### Соцсети и тема
- Новый файл `socials.json` в корне репозитория сборки (объект `{"discord": "url", ...}` или массив) — ссылки на соцсети автора появляются в шапке сборки (`https://` только, до 8 ссылок, имя выводится из домена).
- Новый файл `theme.json` в корне репозитория сборки — цвета лаунчера подстраиваются под стиль автора: при открытии сборки интерфейс плавно (0.6 с) перекрашивается в выбранные цвета (bg/panel/input/border/tx/txStrong/txMuted/accent/accentStrong/accentHover/accentDeep, формат `#rrggbb`).
- Новости сборки убраны из шапки: лента новостей — только на отдельной странице «Новости» (переключатель и localStorage `nio.newsHidden` удалены).

### Оффлайн-скины
- Настройки → «Скин»: выбор PNG (64×32 или 64×64, Steve/Alex), скин привязан к нику и загружается в публичный скин-сервис.
- При запуске в оффлайн-режиме к игре подключается `authlib-injector` (`-javaagent`), поэтому свой скин видно в одиночке и на серверах, подключённых к тому же скин-сервису.
- Разработчики серверов подключают скин-сервис одной строкой (authlib-injector) — адрес показан в настройках лаунчера; подробности и инструкции в `skins-api/README.md`.

- Кастомные моды (файлы не с CDN Modrinth/CurseForge и `.jar` из `overrides`) помечаются в `.nio-custom.json` и показываются в предупреждающем баннере вкладки игры.
