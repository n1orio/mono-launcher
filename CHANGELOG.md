# Changelog

## [0.2.2] — 2026-08-11

### Одна игра — один экземпляр
- Запуск второй копии Minecraft поверх уже открытой теперь блокируется (раньше можно было запустить игру дважды подряд): кнопка «Играть» гаснет на время игры («В ИГРЕ»), а при повторной попытке — ошибка «Игра уже запущена».
- Guard живёт в бэкенде: любой способ запуска (кнопка, «Играть на сервере», повторный клик) проверяет, не запущен ли уже клиент (PID игры хранится процессом и снимается при выходе).

### Ачивки → «ещё не запускалась»
- Бейджи-ачивки убраны: вместо них у свежеустановленной сборки показывается пилюля «Ещё не запускалась», которая сменяется часами после первого запуска.

## [0.2.1] — 2026-08-11

### Соцсети сборки — цветные кнопки
- Автор сборки может задать цвет каждой кнопки соцсети в `socials.json` (`color: "#rrggbb"`): кнопка рисуется в фирменном цвете (Discord, Telegram, YouTube и т.д.); без цвета — акцент темы лаунчера.

### Минимальная оперативка — заметный бейдж
- «≥ N ГБ» теперь показывается в шапке сборки рядом со статусом установки (оранжевый, когда выделенной RAM не хватает), а не в строке метаданных.

### Предупреждение о модах можно скрыть
- Новая настройка «Предупреждение о модах»: плашку «обнаружены моды не с Modrinth/CurseForge» можно отключить (и снова включить) в Настройках — хранится в `warn-custom-mods.txt`.

### Прочее
- CI: тело релиза на GitHub заполняется автоматически из CHANGELOG.md.

## [0.2.0] — 2026-08-11

### Платные сборки через Boosty
- Платность сборки настраивается никем блога: опциональный `boostyBlog` в `pack.json` релиза, `packs.json` или встроенных `PACKS` (нет поля — сборка бесплатная).
- Игрок привязывает личный токен Boosty (Настройки Boosty → Приложения): лаунчер проверяет подписку на блог издателя через api.boosty.to — скачивание и запуск открываются только подписчикам (оффлайн-льгота до 3 дней после успешной проверки).
- Ссылка-приглашение несёт `blog=` — сборка добавляется сразу платной; `pack.json` с `boostyBlog` даёт тот же эффект.
- Панель подписки в шапке сборки: статус (до какой даты активна), поле токена, привязка/отвязка.

### Каталог сборок
- Новая вкладка «Каталог»: курируемый список сборок из `catalog.json` (в корне репозитория лаунчера) — описание, автор, теги, платность, минимальная оперативка; кнопки «Добавить» (один клик, с блогом из записи) и «Открыть» для уже добавленных.
- Кнопка «Предложить сборку» — issue с шаблоном для авторов.

### Минимальная оперативка
- Новое поле `minRam` (МБ) в `pack.json`: бейдж «≥ N ГБ» в шапке сборки, подсказка в настройках и блокировка запуска при недостаточном выделении ОЗУ.

### Баг-репорты
- «Сообщить о баге» открывает превью отчёта: окружение (включая RAM и разрешение окна) + хвост launch.log (60 строк) — можно скопировать или открыть Issues.

### Серверы сборок
- Вкладка «Сервера»: статусы серверов прямо в карточках — онлайн/офлайн, игроки, версия, MOTD, пинг (1.7+ status request с фолбэком на legacy 0xFE). Автообновление статусов раз в 45 секунд + кнопка «Обновить статус».
- Кнопка «Играть на сервере»: запускает игру с авто-коннектом (`--server`/`--port` в аргументах клиента).
- Серверы игрока из `servers.dat` установленной версии: показываются отдельной секцией «Мои серверы (из servers.dat)» под серверами автора сборки (адрес + порт парсятся автоматически).

### Скриншоты
- Вкладка «Скриншоты» теперь показывает скриншоты из папки `screenshots` установленной версии сборки (F2 в игре) — с полноэкранным просмотром. `screenshots.json` в репозитории больше не нужен.

### Соцсети и тема
- Новый файл `socials.json` в корне репозитория сборки (объект `{"discord": "url", ...}` или массив) — ссылки на соцсети автора появляются в шапке сборки (`https://` только, до 8 ссылок, имя выводится из домена).
- Новый файл `theme.json` в корне репозитория сборки — цвета лаунчера подстраиваются под стиль автора: при открытии сборки интерфейс плавно (0.6 с) перекрашивается в выбранные цвета (bg/panel/input/border/tx/txStrong/txMuted/accent/accentStrong/accentHover/accentDeep, формат `#rrggbb`).
- Новости сборки убраны из шапки: лента новостей — только на отдельной странице «Новости» (переключатель и localStorage `nio.newsHidden` удалены).

### Оффлайн-скины
- Настройки → «Скин»: выбор PNG (64×32 или 64×64, Steve/Alex), скин привязан к нику и загружается в публичный скин-сервис.
- При запуске в оффлайн-режиме к игре подключается `authlib-injector` (`-javaagent`), поэтому свой скин видно в одиночке и на серверах, подключённых к тому же скин-сервису.
- Разработчики серверов подключают скин-сервис одной строкой (authlib-injector) — адрес показан в настройках лаунчера; подробности и инструкции в `skins-api/README.md`.

## [0.1.6] — 2026-08-10

### Сборки
- Сборки превращены во вкладки в навигации (вместо выпадающего списка): каждая сборка — своя вкладка, в sidbar показан автор (`@owner`), кнопка «открыть репозиторий» и удаление.
- Зелёная кнопка «Создать сборку» — открывает пример сборки и мини-документацию для авторов прямо в лаунчере.
- Новые вкладки в каждой сборке: **Скриншоты** (галерея с полноэкранным просмотром из `screenshots.json`) и **Сервера** (карточки с копированием IP из `servers.json`); в шапке сборки — **звёзды репозитория**.
- Кнопка «Сообщить о баге» — форма Issues репозитория сборки с предзаполненным окружением (версия сборки, Minecraft, лаунчер, ОС).

### Новости
- В ленту новостей добавлены релизы самого лаунчера (рядом с релизами и дискуссиями сборок); для них — кнопка «Открыть» вместо «Установить».

### Безопасность
- Кастомные моды (файлы не с CDN Modrinth/CurseForge и `.jar` из `overrides`) помечаются в `.nio-custom.json` и показываются в предупреждающем баннере вкладки игры.
- Каждый скачанный файл дополнительно проверяется по sha1/sha512 из `modrinth.index.json`: несовпадение удаляет файл и останавливает установку.
- Напоминание: не устанавливайте кастомные моды от непроверенных авторов.

### Прочее
- Обновление README.md, добавлен CHANGELOG.md, актуализирована документация для авторов сборок.
