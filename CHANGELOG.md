# Changelog

## [0.1.6] — 2026-08-10

### Сборки
- Сборки превращены во вкладки в навигации (вместо выпадающего списка): каждая сборка — своя вкладка, в sidbar показан автор (`@owner`), кнопка «открыть репозиторий» и удаление.
- Зелёная кнопка «Создать сборку» — открывает пример сборки и мини-документацию для авторов прямо в лаунчере.
- Новые вкладки в каждой сборке: **Скриншоты** (галерея с полноэкранным просмотром из `screenshots.json`) и **Сервера** (карточки с копированием IP из `servers.json`); в шапке сборки — **звёзды репозитория**.
- Кнопка «Сообщить о баге» — форма Issues репозитория сборки с предзаполненным окружением (версия сборки, Minecraft, лаунчер, ОС).

### Новости
- В ленту новостей добавлены релизы самого лаунчера (рядом с релизами и дискуссиями сборок); для них — кнопка «Открыть» вместо «Установить».

### Безопасность
- Кастомные моды (файлы не с CDN Modrinth/CurseForge и `.jar` из `overrides`) помечаются в `.nio-custom.json` и показываются в предупреждающем баннере вкладки игры.
- Каждый скачанный файл дополнительно проверяется по sha1/sha512 из `modrinth.index.json`: несовпадение удаляет файл и останавливает установку.
- Напоминание: не устанавливайте кастомные моды от непроверенных авторов.

### Прочее
- Обновление README.md, добавлен CHANGELOG.md, актуализирована документация для авторов сборок.
