# Зміни

## [2.0.0-alpha.9] — 2026-09-13

### Інтерфейс
- Заміна глобального `updateInfo` на по-пакетний `updateInfoByPack` (`Record<string, UpdateInfo>`) — плашки оновлень та кнопки прив'язані тільки до активної збірки
- Переписано `refreshModUpdates` з per-pack збереженням стану та хешуванням встановлених версій — більше немає stale-даних при перемиканні збірок
- Виправлено `TabPlay.vue`: `customModsFiles` тепер використовує `watch` на `status.value?.custom_mods` для миттєвої реактивності, виправлено відображення зеленої плашки на всіх збірках
- Додано `currentPackUpdate` computed та `handleUpdate` використовує його замість `updateInfo.value`
- Додано `packBackendMeta` — синхронізується з `meta` бекенду; використовується для перевірки `use_authlib`
- Виправлено `syncPackWithBackend`: `packBackendMeta` скидання при помилці/пустоті, remote versions коректно відстежуються
- Виправлено `load()` `checkForUpdates`: тепер обирається остання версія за `created_at`, а не рядковою сортуванням `version`
- Виправлено NeoForge JPMS падіння: виключено `net.neoforged:neoforge` ТА srg-клієнт (`net/minecraft/client/`) з classpath — FML знаходить їх через `-DlibraryDirectory`, інакше JPMS бачить два модулі `neoforge` і кидає `ResolutionException`
- Виправлено зависання при оновленні збірки: `extract_mrpack` містив `let mut total: u64 = 0`, що перекривав `let total = archive.len()`. `file_total`/`total`/`current` в `DownloadProgress` показували байти поточного файлу замість загальної кількості/байтів, через що фронтенд показував 100% поки розпаковка продовжувалась. Підрахунок `file_total` тепер ведеться тільки по файлах (без директорій), фінальний прогрес 100% завжди емітується після циклу. Також `handleInstall` та `installRemoteVersion` тепер збрасують `progress.value = null` у `finally`, щоб виджет завантаження закрився

## [2.0.0-alpha.7] — 2026-09-06

### Бібліотека
- Єдина розгорнута плашка категорії з попіксельним вирівнюванням сітки.
- Переробка сітки бібліотеки (полірування карток папок).

### Інтерфейс
- Єдиний компонент `AppIcon` (замінює 184 інлайн-SVG).
- Покращено markdown-редактор; додано відсутні ключі перекладу.
- Покращено панель завантажень, налаштування мережі, нескінченну прокрутку каталогу.
- Полірування налаштувань / гри / каталогу; фікс CurseForge CDN.

### CurseForge
- **Фільтр за завантажувачем** — пошук модпаків CurseForge фільтрує за `modLoaderType` (forge / fabric / quilt / neoforge) замість `categoryId`.
- **Автофільтри** — відкриття збірки автоматично застосовує фільтри зі статусу пака.
- **Повні описи** — картки модпаків показують повний HTML (prose-стилі) замість короткого summary.
- **Нескінченна прокрутка** результатів пошуку.

### Контекстні меню
- ПКМ по збірці в сайдбарі → Грати / Налаштування / Новини / Видалити.
- ПКМ по файлу у списку → Деталі / Оновити / Увімк-Вимк / Видалити / Відкрити теку.
- Повторно використовувані компоненти `AppContextMenu` та `AppContextMenuItem`.

### Тулбар
- Меню «...» із секціями: керування модами, операції з файлами, видалення.
- Кнопку видалення перенесено у випадайку (червона іконка).

### Інтерфейс
- Масштаб шрифту: 13px → 14px.
- Розмір вікна: 1200×750, мінімум 950×650.
- Хелпер `enableAllFiles()` для масових операцій увімк/вимк.

### Виправлення
- Відновлено відсутні файли компонентів (tabs/, modals/).
- Версію піднято до 2.0.0-alpha.7 в усіх конфігах (package.json, tauri.conf.json, Cargo.toml, локалі).

## [1.3.1] — 2026-08-18

### Моди та сховище
- Нова вкладка **«Дублікати»** сканує `mods/`, `resourcepacks/` і `shaderpacks/` та групує файли з однаковим вмістом (за розміром + SHA-1). Показує, скільки місця можна звільнити, дозволяє видалити один файл або залишити по одному в групі.

### Скріншоти
- Скріншоти тепер показують **дату та час** зйомки — бейджем на кожній плитці та в повноекранному перегляді.

## [1.3.0] — 2026-08-18

### Бібліотека
- Нова вкладка **«Бібліотека»**: усі встановлені збірки, згруповані за категоріями, плитки з масштабуванням.
- Кожна плитка показує активний модлоадер/версію або «не встановлено»; категорії можна ховати.
- Новий розділ **«Нещодавні»** у сайдбарі показує останні запущені збірки (до 10).

### Брендинг збірок
- **Перейменування збірки** прямо з інтерфейсу — для вбудованих збірок зберігається на екземпляр, для користувацьких оновлюється `packs.json`.
- **Завантаження власного банера** (редагування іконки вже було) — зберігається локально.

### Моди та оновлення
- Встановлені вручну моди тепер показують реальні метадані — іконку Modrinth/CurseForge, назву проєкту та версію — замість сирих імен файлів.
- **«Оновити все» тепер по вкладках** (моди / ресурспаки / шейдери), з лічильником.
- Пошук Modrinth отримав **фільтр типу версії** (Релиз/Бета/Альфа), фільтр завантажувача, «Завантажити ще» та «Скинути фільтри».
- «Завислі» записи відстежуваних модів (файли вже видалено з диска) чистляться, тож значок оновлення більше не показує примарні оновлення.

### Геймплей та інтерфейс
- Поки гра запущена, кнопка «Грати» перетворюється на червону **«Зупинити»**, яка завершує процес, із коректним виходом (без хибного «гра впала» при навмисній зупинці).
- Основна панель інтерфейсу тепер **по центру** екрана, а не розтягується від краю до краю.

### Під капотом
- Новий персистентний **HTTP-кеш** (умовні запити ETag/304), щоб повторні запуски лаунчера не тягли мережу без змін.
- Розширені Rust-юніт-тести; перевірка типів фронтенду.
